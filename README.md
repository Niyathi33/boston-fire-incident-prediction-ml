# Optimizing Emergency Response with Fire Incident Data: A Case Study of Boston

## Overview

This project uses machine learning and predictive analytics to analyze historical fire incident data from Boston.

The goal is to identify high-risk fire incidents, reduce false alarms, and support better emergency response planning.



## Problem Statement

Emergency response teams need accurate and timely information to reduce property damage and improve response efficiency.

This project focuses on:
- identifying patterns in fire incident data
- predicting high-risk incidents
- improving operational decision-making using machine learning



## Models Used

- Logistic Regression
- Random Forest
- XGBoost
- LightGBM

Additional techniques used:
- SMOTE for class balancing
- SelectKBest for feature selection
- GridSearchCV for tuning

## Dataset

The dataset used in this project is not included in this repository due to its large size.

To run the project:
1. Create a folder named `data`
2. Place the dataset file inside the `data/` folder
3. Update the dataset path in the notebook if needed

Example:

data/
   dataset.xlsx
